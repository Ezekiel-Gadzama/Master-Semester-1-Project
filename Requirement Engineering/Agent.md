# Requirement Engineering — course agent

Read this file after the workspace `AGENTS.md`. Then follow `AGENTS.md` §3.

Official course Telegram export (when you have it): `Course chat/` in this folder, latest `ChatExport_*`. Search for this assignment’s name and deadline. Team chat is `{team name} chat/` at the workspace root.

Then read any course-wide rule or rubric files here, then that assignment’s `Materials/`. Do not invent requirements, stakeholders, or citations.

## Course-wide rules

Put the RE equivalent of MSD's `CASE-RULES.pdf` here (and as a PDF next to this file) when the course handout is available: how assignments run, page limits, citation style, what sources are allowed.

Until then, follow the workspace `AGENTS.md` for the shared title page and LaTeX layout, and treat each assignment's `Materials/` as the source of truth for that piece of work.

## Title page

One page, using `coursereporttitle`. Same shared layout as MSD: title, subtitle, course/date, team, **Member / Contribution** table (`\member{Name}{what they did}`), then this course's citation-key paragraph. Do not copy MSD's “p.N / Exhibit / L1a” wording unless RE actually uses it.

## New assignment

Copy `common/assignment-template` into `Requirement Engineering/<id>/`, add `Materials/`, then fill the title page and bibliography from this file and that brief.
